# Slash homepage recreation

A responsive recreation of the Slash homepage built with TypeScript, Next.js 16 App Router, React 19, Tailwind CSS and shadcn/ui.

## Run

Install Node.js 20.9+ and pnpm, then run `pnpm install` and `pnpm dev`. Run `pnpm build` to generate the static site in `out/`.

## Included

Announcement, navigation, hero, customer logos and stories, financial product cards, modern capabilities, testimonial carousel, metrics, intelligent tools, interactive security accordion, Free/Pro pricing, investor strip, FAQs, insights carousel, signup CTA, footer and disclosures. Responsive layouts, keyboard controls, reduced-motion support and local fonts are included.

This is an independent frontend design recreation, not an official Slash service. Reference: https://www.slash.com/ (September 2026). Original brand imagery and font assets belong to their respective owners. Product copy and disclosures are for reference; official terms govern.

Forms validate email locally and show a dialog linking to the official registration page. They do not save or submit personal data. Product and article links go to Slash. No banking backend, authentication, analytics, or financial transactions are implemented. Capabilities without supplied imagery are represented by illustrative dashboard UI. Legal text is condensed with links to official disclosures.

The full shadcn component catalog is retained from the Sites scaffold. Next.js performs the application build; Vite configuration is scaffold metadata and is not used by the build scripts.
